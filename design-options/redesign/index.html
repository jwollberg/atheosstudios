Before we build

Things to check

  • New headline: "Worlds that run on their own rules." The old line, "realism-first survival games," doesn't fit Elderdeep, so it's replaced.
  • New studio claim: every game is built in-house, "engine and all." That's true of all three projects, but say so if you'd rather not advertise it.
  • Statuses: Grave Error "Coming eventually," Elderdeep "In development," Holdout "Early development," with a "Working title" tag. All three say PC.
  • Taglines are new: "An endless world, all the way down." (Elderdeep) and "Hold the line. Grow the camp." (Holdout).
  • Only Grave Error links out. Elderdeep and Holdout say "More to come" until they have pages.
  • Art is placeholder. The drawings stand in for real key art or screenshots, which can drop into the same spots later.
